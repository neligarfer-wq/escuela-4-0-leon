# Escuela 4.0 en el aula

Guía práctica para que el profesorado de Infantil, Primaria y Secundaria empiece a utilizar los recursos de Código Escuela 4.0 en el aula.

## Web pública

- [Abrir la web](https://guia-escuela-40-cyl.neligarfer.chatgpt.site)
- Cuando GitHub Pages esté activado: `https://neligarfer-wq.github.io/escuela-4-0-leon/`

## Desarrollo local

```bash
npm install
npm run dev
```

## Publicación

El flujo de GitHub Actions incluido genera y publica automáticamente la versión estática cuando se suben cambios a la rama `codice-tic`.
